# Constitution

The project rules are the constitution. They are in `.agents/rules/`. Read the one that
your step touches.

- `global.md` — how much process a change gets, and the habits that hold for all work.
- `development.md` — the architecture standard.
- `technical-writing.md` — the writing standard for a spec, a plan and a task list.
- `github-source-control.md` — branches, pull requests and review.

A spec, a plan or a task list that conflicts with a rule is wrong. Change the artifact,
not the rule.

## Project principles

Add a principle here only when it is specific to this project and no rule states it.
